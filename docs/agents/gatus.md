# Gatus (status probing) — agent topic guide

Part of the `AGENTS.md` topic guides (`docs/agents/`). Read when adding/moving routes and
wanting their Gatus endpoints to be correct, or when an endpoint is red for probe-shaped
reasons.

- `gatus-sidecar --auto-httproute` derives one endpoint per HTTPRoute and **the probe URL from the HTTPRoute rule path**, not from the hostname root (`--enable-service` likewise) — so a route whose first rule is a path-specific workaround gets probed there. Plex was red for a long time because its route's first rule is `PathPrefix /library/streams`; the fix is an explicit `url:` in the `gatus.home-operations.com/endpoint` annotation (`plex` now probes `/identity`, PMS' anonymous identity endpoint).
- The sidecar also deep-merges the parent Gateway's annotation into each child route (child wins on scalars).
- Routes whose handler rejects GET need a matching condition instead of `== 200`: the POST-only webhook receivers (Flux `github-webhook`, konflate `/hooks`) assert `conditions: ["[STATUS] == 404"]`, which the app answers with Go's own `404 page not found` — do not switch those to a POST probe.
- Endpoints behind Authentik must probe a liveness path, because an unauthenticated probe of `/` gets a 302 instead of 200. There is no single such path (`*arr` `/ping`, clonarr/umlautadaptarrex `/api/health`, echo/flux-operator/konflate `/healthz`, grafana `/api/health`, prometheus/alertmanager `/-/healthy`, victoria-logs `/health` — full table in `docs/authentik-forward-auth.md`). An in-cluster probe from a throwaway pod finds candidates but is not proof (apps may exempt local addresses); confirm the path through the gateway without credentials after a migration.
- Recipe per app: set `skip_path_regex` on the ProxyProvider (`docs/agents/authentik.md`), override the URL per route with `gatus.home-operations.com/endpoint: |- url: https://<app>.480p.com/<path>`, and set `gatus.home-operations.com/enabled: "false"` on the `*-outpost` HTTPRoute — otherwise the sidecar also emits a bogus endpoint for `https://<app>.480p.com/outpost.goauthentik.io`.
- If an app has no anonymous liveness path: assert its own auth challenge (`conditions: ["[STATUS] == 401"]`, as a WebDAV route's own challenge did) or its own not-found (`[STATUS] == 404`, as `kopia` does — its `/healthz` is skipped from ext-auth and a probe on `/` would only prove Authentik answered) or disable that endpoint. vaultwarden's `/admin` asserts the outpost's `[STATUS] == 302` with `client.ignore-redirect: true` (gatus follows redirects by default and would otherwise assert the sso login form).
- The Gateway's inherited `Authorization: Basic ${GATUS_TINYAUTH_BASIC_AUTH}` header is harmless on skipped paths (the outpost evaluates `skip_path_regex` before basic auth) and can stay until TinyAuth is fully retired.
